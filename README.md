Library System Website

The Library System Website is a modern, user-friendly web application designed to manage book borrowing for a library. It allows users to register, log in, search for books, borrow books, and manage their profile (view/update username and email, view borrowing history). The website features a vibrant, responsive design with glassmorphism, gradients, and smooth animations, inspired by real-world library platforms like OverDrive and WorldCat.

Features





User Authentication: Register and log in securely.



Book Search: Search books by title, author, or category, with sorting and filtering options.



Borrowing: Borrow books and view borrowing history.



Profile Management: View and update username and email, view borrowing history, and log out.



Responsive Design: Works seamlessly on desktop and mobile devices.



Modern UI/UX: Vibrant colors, glassmorphism, and animations for an engaging experience.

Technologies Used





Frontend: HTML, CSS, JavaScript



Backend: PHP



Database: MySQL



Server: Apache (via XAMPP or similar)



External Libraries: Font Awesome (for icons)
